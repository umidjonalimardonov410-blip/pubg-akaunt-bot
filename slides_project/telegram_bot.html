Technical Integration

  • Mini App Launcher: Native menu button configured via `setChatMenuButton` for instant access.
  • Signed Webhooks: Validation using `X-Telegram-Bot-Api-Secret-Token` to prevent unauthorized requests.
  • Outbound Alerts: Real-time notifications for price drops, escrow updates, and admin messages.
  • Inline Keyboards: Dynamic buttons linking directly to specific Mini App routes (e.g., order details).
